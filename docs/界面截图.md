# 界面截图

运行截图来自 Flutter Web release 构建，主视口 390 × 844 @2x。Pixso 原稿为 375 × 812；导出时透明背景合成为浅色底，以便查看。

相机页面为 App 内封面入口与导入照片后的预览；系统相机的具体界面取决于设备。录音使用合成音频流，编码、持久化与播放执行真实插件流程。
